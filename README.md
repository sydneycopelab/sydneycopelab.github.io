# Conflict and Peace Economics Lab

Static website for the Conflict and Peace Economics Lab, built for GitHub Pages.

## Publishing

The site has no build step. It loads the open-source DM Serif Display and DM Sans families from Google Fonts. In the repository settings on GitHub, set **Pages → Build and deployment → Source** to **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.

## Updating content

- Page content is in `index.html`.
- Visual styling and responsive layouts are in `styles.css`.
- Navigation, scroll effects, and publication filters are in `script.js`.
- The header uses the standalone mark in `assets/my_plot.svg`, paired with a text wordmark in the page markup.
